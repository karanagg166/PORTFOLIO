# Karan Aggarwal - Personal Portfolio

Modern Next.js portfolio website built with Framer Motion, Tailwind CSS, and Aceternity UI components.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, Framer Motion
- **Icons & UI**: React Icons, Aceternity UI
- **Integrations**: GitHub API (PR fetcher)

## Features
- **Hero & Intro**: Dynamic flip words, intro, and high-performance spotlight effects.
- **Bento Grid**: Highlights education (PDPM IIITDM Jabalpur), origin (Faridabad, Haryana), competitive programming ratings (Codeforces Expert 1602, LeetCode Knight 1916), and tech stack.
- **Projects**: Interactive cards for **Exam-Arena**, **Quick Clinic**, **LogiSync**, and **Shop Sizzle**.
- **Experience**: Timeline showcasing internship at **Akatsuki AI Technologies** and full-stack projects.
- **GitHub PR Tracker**: Real-time integration fetching pull requests directly for GitHub user `karanagg166`.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
