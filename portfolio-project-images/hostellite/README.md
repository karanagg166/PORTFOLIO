# Hostellite

Hostellite is a 100% native iOS mobile application built with Apple's SwiftUI framework and Swift Concurrency (`Hostellite/HostelliteApp.swift`).

### Environment & Capture Status
- **Target Platform**: Apple iOS (iPhone / iPad)
- **Framework**: SwiftUI / iOS SDK
- **Execution Requirement**: Full Apple Xcode IDE (`xcodebuild`), Xcode command-line tools, and booted Apple iOS Simulator / Physical iPhone runtime.
- **CLI Environment**: On this headless Darwin shell environment, full Xcode.app and iOS Simulator runtimes are not installed or available (`xcodebuild` unavailable).
- **Integrity Guarantee**: In strict accordance with the developer portfolio requirements (*"Do NOT generate fake screenshots to replace a project that cannot be accessed. The screenshots must come from the actual projects."*), no mock or simulated UI has been substituted.
